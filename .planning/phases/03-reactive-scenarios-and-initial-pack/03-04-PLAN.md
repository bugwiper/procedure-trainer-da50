## Phase goal

Users can run all three initial emergencies (Oil Temp High, Electrical Failure, Engine Fire) and see each one react to what they do: gauges move, ignored failures escalate, handled failures recover. (ROADMAP Phase 3, Mode mvp, goal kept verbatim.) This plan adds the event-triggered, timed reaction of SCN-06 and the retract and consumed rules every later reaction relies on.

<objective>
Add one-shot reactions with timers to the simulation, make the run raise the store's consumed watermark when a reaction fires, rebuild the run by replay when an applied event is retracted, and deliver the de-ice MAX 120 s run with its lamp.

Purpose: D-03 (consume only when a reaction fires; a removed event leaves nothing armed), D-04 (the MAX run exercises the clock and flag path), SCN-06 (timers, triggers on user actions). Folded todos: `2026-10-21-deice-max-timer-engine.md` (item 1 only) and `2026-10-21-retract-consumed-events-phase3.md`.
Output: reactions in physics and sim, the run's watermark and rebuild, the bridge's flags signal, the MAX reaction, unit and e2e cases.
</objective>

## Defaults used by this plan

| ID | Default | Why |
|----|---------|-----|
| C-20 | A reaction is aircraft data: an id, the event that arms it (a control entering a state), a condition over the controls at that moment, the flag it sets, a duration and a condition over the controls that clears it at once. Step order: (1) apply the due events one by one in log order; after each, a reaction whose event matches and whose condition holds starts (flag on, timer at the duration) unless it is already active (RESEARCH A9: a press during a run is ignored); (2) an active reaction whose clear condition holds stops at once; (3) the physics models (they may read the flags); (4) every active timer counts down by STEP_MS and the flag goes off at 0 | The press must trigger on the event, not on a state poll: a press and release can fall into one step (RESEARCH "De-ice MAX run") |
| C-21 | When a reaction starts, the run calls store.markConsumed with the seq of the newest event that started a reaction in that step | D-03: consume only when a reaction fires |
| C-22 | A retract of an event the run already applied rebuilds the run state with simulate over the remaining log up to the current run time; a retract of an event not yet applied needs no rebuild | D-03 and RESEARCH Pattern 3: replay makes cancellation exact |
| C-23 | Closing the debrief clears the flags (a run timer cannot outlive its run); the quantities stay as the run left them; on the free panel no reaction runs (plan 01, C-04) | Without a clock a lit MAX lamp would stay lit forever on the free panel; the free-panel simulation is a follow-up todo written in plan 09 |
