## Phase goal

Users can run all three initial emergencies (Oil Temp High, Electrical Failure, Engine Fire) and see each one react to what they do: gauges move, ignored failures escalate, handled failures recover. (ROADMAP Phase 3; Mode mvp. The goal line is not written as a user story; it is kept verbatim, as in the earlier MVP phases.) Requirements of the phase: SCN-06, PNL-04, PNL-07, CNT-01. Locked decisions: `03-CONTEXT.md` D-01 to D-12.

After this plan the oil temperature needle of an ENG OIL TEMP run rises when ignored and falls after the correct actions.

## Table P1: the oil temperature model (aircraft data, plan 01)

The model is a lag toward a target computed from the controls and the parameter `oil_cooling` (normal value 1, range from a small positive minimum to 1; the scenario sets a degraded value). Load is the travel percent of POWER (use `travelPercent` of src/engine/predicates.ts on the lever definition); the cowl flap is open or closed. The formula is the executor's choice within these constraints; use only `+ - * /`.

| Case | Controls | oil_cooling | Required target |
|------|----------|-------------|-----------------|
| P1-a cruise anchor | registry defaults (POWER p70, cowl flap closed) | 1 | a cruise value inside the green band (90 proposed); plan 02 makes it the base value of the quantity |
| P1-b ignored | POWER p75, cowl flap closed (the scenario's initial controls) | scenario value | above 140, so an ignored failure keeps climbing past the 128 start |
| P1-c handled | POWER p50, cowl flap open (the golden taps) | scenario value | at most 110, inside the green band |
| P1-d power only | POWER p60, cowl flap closed | scenario value | below P1-b |
| P1-e cowl only | POWER p75, cowl flap open | scenario value | below P1-b |

Rates: a time constant between 20 s and 60 s; from 128 in case P1-b the value rises by at least 1 degree within 3 s; from 128 in case P1-c it falls by at least 1 degree within 3 s. With the engine master OFF the target falls toward 15 (ambient). Plan 05 later puts the escalation threshold between the 20 s do-nothing value and the P1-b target.
