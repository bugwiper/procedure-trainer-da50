## Phase goal

Users can run all three initial emergencies (Oil Temp High, Electrical Failure, Engine Fire) and see each one react to what they do: gauges move, ignored failures escalate, handled failures recover. (ROADMAP Phase 3, Mode mvp, goal kept verbatim.) This plan delivers ROADMAP criterion 4: the user can enter a squawk code (for example 7700) in a simplified transponder section, and the entered code counts as graded panel state.

<objective>
Add the simplified transponder of D-11: a new control kind whose state is the committed four-digit code, a widget in the pilot's legroom with keys 0 to 7, CLR and a readout, and every layout, label and gesture gate the panel already has.

Purpose: PNL-07 and D-11. A momentary key cannot carry a digit and a rotary knob has at most 5 stops, and the predicate vocabulary has no conjunction, so the code needs one control whose state is the whole code (RESEARCH "Transponder").
Output: the code-entry kind, kp.squawk with its region and plate, the CodeEntry widget, unit, layout, label and e2e gates.
</objective>
