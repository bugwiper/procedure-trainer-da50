## Phase goal

Users can run all three initial emergencies (Oil Temp High, Electrical Failure, Engine Fire) and see each one react to what they do: gauges move, ignored failures escalate, handled failures recover. (ROADMAP Phase 3, Mode mvp, goal kept verbatim.) This plan delivers ROADMAP criterion 1a, the level "realistic" (owner request from the phase 2 UAT).

<objective>
Add the level Realistic: chosen on the level card, it starts the run at once in the base state with no briefing, the failure begins by itself after a seeded random delay inside the scenario's onset window, the reaction time is measured from the onset, and the debrief reveals the scenario. A lint rule guarantees that a realistic do-nothing run starts clean and shows every annunciation the scenario lists.

Purpose: D-05 and ROADMAP criterion 1a; the Phase 2 instructor note (time limits and their reference point belong with Phase 3) is answered: no limits, reference point is the onset, shown for display.
Output: the onset window in the schema, the seeded onset, Recording.onset and GradeResult.timing, the realistic session flow, the level card, the debrief reveal and timing line, lint L14, unit and e2e cases.
</objective>
