## Phase goal

Users can run all three initial emergencies (Oil Temp High, Electrical Failure, Engine Fire) and see each one react to what they do: gauges move, ignored failures escalate, handled failures recover. (ROADMAP Phase 3, Mode mvp, goal kept verbatim.) This plan is the data half of the UAT gap of test 10: the checklists must be the official ones, word for word, as a numbered table or as the printed outline.

Purpose: UAT test 10 (owner): "checklist formatting is too jumbled; it must be tabular and numbered like the official one, 1:1 accurate, no rephrasing; copyright is not a concern".

</objective>
