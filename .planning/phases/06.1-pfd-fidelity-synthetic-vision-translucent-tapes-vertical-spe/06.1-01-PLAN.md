## Decisions (assumptions taken in planning; the owner may veto any of them)
Owner decisions D-01 to D-06 and D-14 to D-18 of `06.1-CONTEXT.md` apply. No shipped scenario, rule or grading is touched; `tests/fixtures/recordings.json` stays unchanged.
- **C-01 (D-03, D-04) The column.** `src/aircraft/da50rg/pfd-layout.ts` (new) holds the layout data the gates read. Plan 01 puts in it the content zone (`PFD_ZONE`: x 4 to 491 as the zone gate of `e2e/glass.spec.ts` uses, y from `GLASS.content`), the altitude block (`ALTITUDE_BLOCK`, one x) and `CAS_COLUMN` (x 437, width 52, row height 9, bottom edge 341, text baseline 6.5 below the row top, `maxRows` read from `MAX_CAS_CHIPS`). The pure function `casColumnRows(count)` returns the rectangles of the first min(count, maxRows) messages from the top row down: n rows, row i at y = bottom - (n - i) * rowHeight, same x and width, so rows touch and the bottom edge never moves. Row 0 is the first message of the list. It uses `+ - * /` and clamping only.
- **C-02 (D-05) Fine type.** The chip text gets the attribute font-size 6 and loses the bold attribute. The panel stylesheet forces weight 700 and letter spacing 0.06em on every panel text, and a CSS rule beats the SVG attribute, so `src/ui/stage.css` gets a scoped rule for the text inside the group with test id `cas-chips` (weight 400, letter spacing about 0.02em), written like the existing rule for the engine page. The 12-character texts ENG OIL TEMP must fit with at least 2 units to spare on each side at the widest font the project loads; if they do not, widen the row (not the size) within the "about half" range of the reference.
- **C-03 Room.** The old chips stood over the attitude art. The column takes the lower right corner, so the altitude block moves 50 units left: tape (old x 405 to 485) to x 355 to 435, with its tick marks, readout box, FT label, baro box and VS box, all through the one constant `ALTITUDE_BLOCK.x` and the old offsets inside the block. The bank scale tick at 60 degrees reaches x 350.5 and clears the tape. The old baro and VS boxes stay (plan 03 replaces them). Every other PFD number stays inline until plan 02.
- **C-04 Removal.** The slot grid (`casChipSlots`, the slot type and its constants) goes; the typecheck proves nothing else used it. The chips are drawn last in the content group so nothing covers them.
- **Owner review points** (plan 03 puts them into docs/PANEL-REVIEW.md "Phase 6.1: owner review"): the severity order top to bottom; the size, weight and width of the rows; the place at the lower right; the growth upward with the bottom edge fixed.
