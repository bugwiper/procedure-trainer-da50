## Accomplishments

- **Registry:** `BREAKER_GROUPS` (essential, main, avionics, lower, strip), `CircuitBreakerDef` in the `ControlDef` union, `KIND_PREFIX['circuit-breaker'] = 'cb.'`, `checkCircuitBreaker` called from `defineRegistry`. Each failure throws a `RegistryError` naming the control id: states not exactly in then out, default not in, blank rating, empty or blank label lines, label lines that do not match the label (whitespace ignored), group outside the vocabulary, non-positive hit side.
- **Skin and widget:** `BreakerBody` draws Table A2 exactly (socket r 13, cap r 11 or 11.4 with the (-2, -2) offset when pulled, shadow, white ring r 12.5 stroke 2.5 only when pulled, pressed ring only while a pointer is down; compact set for the 24 wide lower-row hit). Label lines carry `data-breaker-label`; the last line sits 16 above the centre, earlier lines 7 higher. No IN or OUT word and no `data-state-text`. `CircuitBreaker` copies the Toggle pointer contract (primary pointer only, capture in try, actuate on pointerup within 10 px via the exported `tapTarget`, no click) and exposes `data-control-id`, `data-kind`, `data-state`, `data-group`, `data-rating`, `role="img"` and `aria-label="CIRCUIT BREAKER PITOT: IN"` (or OUT).
- **Data:** `controls/breakers.ts` holds the grid constants of Table A3 (columns, rows, lower row, flap strip, hits), `CB_REGIONS` with `cb_essential` {1884, 215, 260, 152}, a typed `BreakerRow` table with the cb.pitot row, `breakerSpec` and `BREAKER_CONTROLS`. `panel.ts` spreads `CB_REGIONS` after `right_panel` and `BREAKER_CONTROLS` into the controls. 42 non-guard controls, 13 lamps, 20 regions.
- **Gates without hard-coded counts:** `CB_REFERENCE` (one independent row, tolerance 8, review true) and `ALL_REGION_IDS` (the 19 old ids plus `cb_essential`) in `tests/layout-reference.ts`. `layout.test.ts` loops over `REFERENCE_POSITIONS`, `CB_REFERENCE` and `INDICATOR_POSITIONS`, the completeness gate compares sorted registry ids with the two control tables, the inventory case compares counts and sorted region ids with the tables (title without numbers). `registry.test.ts` and the README sentence case use the same tables; `e2e/layout.spec.ts` imports `ALL_REGION_IDS`. README now reads "42 controls and 13 indicator lamps in 20 regions".
- **Tests of the kind:** 11 registry cases, 27 skin cases (`tests/breaker-skin.test.ts`: same strings in and out, ring only when out, cap moves, element count at most 12, label baselines, visible extent inside the hit in both states and pressed for normal and compact), a "circuit breaker family text is state-independent" block in `static-text.test.ts`, four store cases (start in, pull logs one event with seq 0 and source user, second tap logs a second event, unchanged / illegal-state / unknown rejected), a `targetSide` case and a cb_essential tap-size case (51.3 px on the phone profile) in `zoom.test.ts`. `MIN_VIEW_WIDTH` is untouched (200) and the portrait pinch case passes with the 28 x 28 hit.
- **E2E:** `e2e/breaker.spec.ts` on desktop-chromium and phone-chromium (touch projects zoom into cb_essential first by tapping a background point): starts in with no ring and the aria name; a tap gives data-state out with exactly one ring and a moved cap, a second tap removes it; the panel text list is identical before and after, the breaker prints only `20` and `PITOT`, no `data-state-text` node exists; with the hook the first tap appends exactly one event `{cb.pitot, out}`.
- **Wording:** ROADMAP success criterion 1 and REQUIREMENTS PNL-12 now say a pulled breaker is shown by a raised cap and a white ring and no state text (owner rule G-0.1); one changed line in each file, no box ticked. The override is recorded as P2-03 in `docs/PANEL-REVIEW.md` with the cost of undoing (one skin function and two wording lines), and `tests/panel-review.test.ts` requires the label. `docs/PANEL-LABELS.md` and `docs/PANEL-REVIEW.md` gained a "Circuit breakers" section with the `cb.pitot` row each.

A screenshot of the built panel (2200 x 1400, kept outside the repo) shows cb.pitot pushed in (flush cap, rating 20, PITOT above, no ring) and, after one click, pulled (cap raised up and left, white ring).
