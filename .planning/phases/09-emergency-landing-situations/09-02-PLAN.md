## Decisions (assumptions taken in planning; the owner may veto any of them)
Phase decisions D-02, D-03, D-08, D-11, D-14 and D-15 of `09-CONTEXT.md` apply. Planner details:
- **P-01 The offer.** A pure function in `debrief-text.ts` decides the offer from the graded result, the scenario's `further.follow_on` and the aircraft data: the conduct selected at the end (`result.further.conduct.last`) is a key of the map. It is the same value `furtherNote` reads, so the note ("not trained yet") and the button can be decided from one place: the note shows only when no button does.
- **P-02 The start.** `continueToFollowOn` is `openBriefing(ref, true)` behind the same `loading` guard, busy handling and load-failure memory as Next situation; it differs only in the target. It does nothing outside the debrief or while a load runs.
- **P-03 The button.** Text and title come from aircraft data (`followOn: { label, title }` on the conduct option); the debrief prints them and names no scenario. Visible text is the label, the title is the `aria-label` and the tooltip. Test id `debrief-follow-on`, placed first of the actions after Retry; it is a secondary button.
- **P-04 Stopped engine.** `engine_stopped` is read in `running()` only; no other function learns it.
