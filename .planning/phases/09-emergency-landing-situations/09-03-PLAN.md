## Decisions (assumptions taken in planning; the owner may veto any of them)
Phase decisions D-01, D-02, D-04, D-09 to D-15 of `09-CONTEXT.md` apply; the open question there decides which source the typing uses (A the booklet pages, B the AFM form for the engine-off situation only, C no engine-power checklist exists). Four tasks on purpose: the first is the owner checkpoint.
- **P-01 Typing.** Text, row marks, actions, comment lines and the boxed references are typed from the photo exactly as printed (CONTENT-POLICY section 2); each typed file is read a second time against the photo before it is committed; an own addition (for example a graded step for a panel action the page does not list) is marked in the file header comment. The photos stay in `.input/`, never committed, never quoted in documents beyond the policy.
- **P-02 Which rows are steps.** A printed row becomes a graded step only when the panel has a control that shows its desired state (registry ids such as the POWER lever, ENGINE MASTER, FUEL selector, ELECT. MASTER, the emergency fuel pump, the door release lever, the emergency window, flaps, gear); the severity follows the printed page and the other fire files (the shut-off rows critical, comfort rows optional). Every other row (belts and harnesses, sun visors, keypad, airspeed wording) is a plain `line` without `done`: the sheet lets the user tick it (Phase 7 R-23), the grade never sees it. Order groups follow the printed order only where the page makes the order matter; every choice is listed in the file header and in `docs/PANEL-REVIEW.md`.
- **P-03 Values.** Start height, glide and descent values are instructor-review values chosen so that a do-nothing run reaches the field in about a minute and a half (the pilot has time for the printed rows) and the field is already in sight at the start: for the situation without power the glide speed is the printed best-glide airspeed of the page if it prints one, with `engine_stopped` set in the profile; with power the powered regime descends. The terrain stays the aircraft's normal one (a shipped-file test checks it).
