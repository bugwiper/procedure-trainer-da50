## Phase Goal

**As a** DA50 RG pilot or student, **I want to** open the deployed trainer on my desktop, tablet or phone and operate the panel's switches, guarded switches, levers and buttons by mouse or touch, **so that** I can later rehearse emergency procedures by actually operating the controls.

## Walking Skeleton role

Second skeleton slice: the first real registry control, operated through the pure panel store (the project's "data layer"; there is no database) and rendered from region data. After this plan a user can flip a real switch and see the state change. Plan 04 deploys it.

<objective>
Wire one real control, ENGINE MASTER, end to end: registry data -> PanelStore.dispatch -> signals bridge -> SVG Toggle widget -> visible state, verified by mouse and by tap on every device project. Then add the data-driven layout geometry test that every later plan's controls must pass. The test-first pinning of the full registry and store contract (every invariant, every rejection path, the guard interlock) is plan 08, which runs in wave 3 in parallel with the deploy, lever and glass plans.

Purpose: PNL-02 (registry, stable ids, legal states), PNL-01 (first operable control), PNL-05 (regions as data), PNL-06 (neutral areas emit nothing; guard interlock in the store), PNL-08 (real positions, checked by the reference ordering table). Decisions D-01, D-03, D-04, D-04a, D-06, D-07b (de-ice region), D-07c (engine area, lower switch row, under-panel regions), D-07d (in-flight defaults, ENGINE below DE-ICE, FLAPS and GEAR on the front panel), D-08, D-09, D-13, D-19 (positional fidelity; touch sizing never relocates), D-20 (full-view floor for desktop and tablet; phones zoom, plan 09).
Output: engine registry and store, DA50 RG region and control data, bridge, Panel, ControlWidget, Toggle, one e2e spec, the layout unit test.

src/engine/registry.ts
```typescript
export type ControlId = string;
export type StateId = string;
export const CONTROL_ID_PATTERN: RegExp; // /^[a-z][a-z0-9_]*(\.[a-z0-9_]+)+$/
export interface StateDef { readonly id: StateId; readonly label: string } // label = small state text (D-13)
export interface Size { readonly w: number; readonly h: number }
export interface Rect { readonly x: number; readonly y: number; readonly w: number; readonly h: number }
interface ControlBase {
  readonly id: ControlId;
  readonly label: string;   // ALL CAPS placard text (D-10)
  readonly region: string;  // RegionDef.id
  readonly x: number;       // region-local centre of the control
  readonly y: number;
  readonly hit: Size;       // footprint centred on (x, y); every interactive sub-target of the control lies inside it
}
export interface ToggleDef extends ControlBase {
  readonly kind: 'toggle'; readonly states: readonly [StateDef, StateDef]; readonly default: StateId;
  readonly skin?: 'switch' | 'softkey';
}
export interface GuardedToggleDef extends ControlBase {
  readonly kind: 'guarded-toggle'; readonly states: readonly [StateDef, StateDef]; readonly default: StateId;
  readonly guardOpenHit: Rect; // where the lifted guard can be tapped closed; x, y = top-left corner as an offset from the control centre (x, y)
}
export interface GuardDef extends ControlBase { // derived by defineRegistry, never authored
  readonly kind: 'guard'; readonly states: readonly [StateDef, StateDef]; // [closed, open]
  readonly default: 'closed'; readonly guards: ControlId; readonly openHit: Rect; // copy of guardOpenHit, same offset convention
}
export interface DetentDef { readonly id: StateId; readonly label: string; readonly pos: number } // 0..1, strictly increasing
export interface DetentLeverDef extends ControlBase {
  readonly kind: 'detent-lever'; readonly detents: readonly DetentDef[]; readonly default: StateId;
  readonly dragOnly?: boolean; // D-07c safety-consequence levers: no detent tap targets; only a deliberate drag of the handle actuates (plan 05)
  readonly markers?: readonly StateId[]; // detents that get a tap target; absent = every detent; levers with many fine steps (POWER) list only a few (plan 05)
  readonly track: { readonly length: number; readonly axis: 'v' | 'h' }; // centred on (x, y); 'v': pos 0 = bottom, 'h': pos 0 = left
}
export interface MomentaryButtonDef extends ControlBase {
  readonly kind: 'momentary-button'; readonly states: readonly [StateDef, StateDef]; // [released, pressed]
  readonly default: StateId; // must be states[0].id
}
export type ControlDef = ToggleDef | GuardedToggleDef | GuardDef | DetentLeverDef | MomentaryButtonDef;
export type ControlKind = ControlDef['kind'];
export type ControlSpec = Exclude<ControlDef, GuardDef>; // what aircraft data authors write
export interface RegionDef { readonly id: string; readonly name: string; readonly bounds: Rect }
export interface Region extends RegionDef { readonly controlIds: readonly ControlId[] }
export interface Registry {
  readonly viewBox: Size;
  readonly regions: readonly Region[];
  readonly controls: readonly ControlDef[]; // declaration order; each derived guard directly after its switch
  get(id: ControlId): ControlDef | undefined;
}
export class RegistryError extends Error {}
export function guardIdFor(switchId: ControlId): ControlId; // `${switchId}.guard`
export function legalStates(def: ControlDef): readonly StateId[];
export function defineRegistry(input: { viewBox: Size; regions: readonly RegionDef[]; controls: readonly ControlSpec[] }): Registry;
```

src/engine/store.ts
```typescript
export interface ControlEvent { readonly seq: number; readonly t: number; readonly id: ControlId; readonly value: StateId; readonly source: 'user' }
export type RejectReason = 'unknown' | 'illegal-state' | 'blocked' | 'unchanged';
export type DispatchResult = { readonly ok: true; readonly event: ControlEvent } | { readonly ok: false; readonly reason: RejectReason };
export class PanelStore {
  constructor(registry: Registry);           // state starts at every control's default
  readonly registry: Registry;
  get(id: ControlId): StateId | undefined;
  snapshot(): Readonly<Record<ControlId, StateId>>;
  events(): readonly ControlEvent[];
  isBlocked(id: ControlId): boolean;          // true for a guarded-toggle whose guard is 'closed'
  dispatch(id: ControlId, value: StateId, t: number): DispatchResult; // RangeError when t is not finite or is negative
  subscribe(listener: (event: ControlEvent) => void): () => void;
}
```

Pointer contract: handle only isPrimary pointers; pointerdown calls setPointerCapture; a pointerup within 10 CSS px of the pointerdown point actuates; pointercancel and lostpointercapture clear transient UI state and actuate nothing; never listen to click (RESEARCH Pattern 5: click after pointerup double-fires).
