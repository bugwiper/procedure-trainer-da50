## Phase Goal

**As a** DA50 RG pilot or student, **I want to** open the deployed trainer on my desktop, tablet or phone and operate the panel's switches, guarded switches, levers and buttons by mouse or touch, **so that** I can later rehearse emergency procedures by actually operating the controls.

(Derived from the ROADMAP Phase 1 goal plus the PROJECT.md core value; the ROADMAP goal line itself is not in user-story form.)

## Walking Skeleton role

This plan is the first slice of the Walking Skeleton recorded in `01-SKELETON.md`: the toolchain, the panel stage and a subpath production build verified in a real browser. Plan 03 adds the first registry control through the pure panel store, and plan 04 deploys that skeleton to GitHub Pages.

**Ordering note:** Task 1 is a blocking legitimacy checkpoint that precedes the tracer because no package may be installed before the user has reviewed the pinned list (threat T-01-SC, RESEARCH.md Package Legitimacy Audit). Task 2 is the first implementation task and is the tracer.
