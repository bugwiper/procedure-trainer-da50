## Data tables

Table S1, the retract contract (owner decision R3-Z3, 2026-10-21: the first actuation is retracted, "removed from the action log (not a counter-event appended), and the state recomputed deterministically from the log (engine replay)"; only the last event, never an event that a time-driven reaction has already consumed):

| Call | Result | Effects |
|------|--------|---------|
| retract(seq) where seq is the last event and above the consumed watermark | ok: the removed event and the restored value of its control | the event leaves the log; the state is the defaults folded with the remaining events; retract listeners called once; dispatch listeners not called |
| retract(seq) for a seq that is not an integer or outside 0 to length minus 1 | refused: unknown-event | nothing changes |
| retract(seq) for an event at or below the consumed watermark | refused: consumed | nothing changes |
| retract(seq) for an existing event that is not the last | refused: not-last | nothing changes |
| markConsumed(throughSeq) | watermark raised to throughSeq (integer, not below the current watermark, below the log length; else RangeError) | later retracts of those events are refused |

Check order: unknown-event, then consumed, then not-last. The watermark starts at minus 1. Time is never an input: the window is the caller's rule.
