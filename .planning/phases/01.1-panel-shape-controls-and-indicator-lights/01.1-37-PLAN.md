## Data tables

Table T1, the press-target registry (src/ui/panel/press-targets.ts; names are the contract of plans 37 to 40):

| Member | Meaning |
|--------|---------|
| PressTarget | cls (latch, momentary or own), optional setPending(on), tap(info) returning the sequence number of the event it recorded or null, press(info), release(), discard(), for own targets an optional dragStartPx, and an optional pairKey (the key a double-tap pair is matched on in plan 40; default the element key) |
| PressInfo | the down point and the up point in client px and the hit element |
| registerPressTarget(el, target) | stores the target for an element in a WeakMap; a null element is ignored; called from a ref callback on every render so the target always closes over the current props |
| pressTargetOf(el) | the target registered for an element or undefined |
| pressKeyOf(el) | the data-detent value if present, else the data-hit value, else null |
| seqOf(result) | the sequence number of a successful dispatch result, null for a rejected one |

Gesture layer additions (zoom.ts): classification of a pointerdown looks up the closest data-hit or data-detent element, gives the descriptor (the registered class and key, dragStartPx for own targets, an unregistered hit is own with dragStartPx 0); a per-pointer record keeps the target and the hit element until the pointer ends; effect pending calls setPending; effect discard calls setPending(false) and discard; effect tap with a key calls tap(info) and then resets the double-tap tracker (control taps never pair in this plan); the pointer is captured on the svg when the machine reports pending or view.

Table T2, the first e2e case table (top of e2e/press.spec.ts, extended by plans 38 and 39): id of the hit element, region to zoom into, how to read the state (the data-state of the group with the same control id), and the kind (toggle, breaker, guard cover):

| Case | Hit id | Region |
|------|--------|--------|
| engine master toggle | sw.engine_master | switch_bank |
| circuit breaker | cb.pitot | cb_essential |
| guard cover | sw.deice_alternate.guard | deice |
