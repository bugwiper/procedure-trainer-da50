# Phase 01.1 Plan 17: Landing gear block order and GEAR TEST lamp test Summary

GEAR TEST now lights all four gear lamps while held, and the landing gear block reads heading, VLE / VLO speed line, then the lamps and the horizontal STALL TEST / GEAR TEST toggle, all on the gear plate.

## What was built

- **Task 1 (tracer, commit d67f1f4):** `gearLamps(gear, inTransit, lampTest = false)`; with the lamp test on all four lamps are lit. The four gear lamp specs read `lv.gear` and `btn.stall_gear_test` and compute the lamp test as `state === 'gear_test'`. Unit cases cover Table G2, the reads list, the store round trip (gear up plus GEAR TEST, neutral, STALL TEST, gear down plus STALL TEST) and the transit flag versus lamp test as separate inputs. An e2e case holds the right half of the toggle with the mouse (lamps lit), releases (lamps off), then holds the left half (state stall_test, lamps off); the touch projects skip it with the same reason as `e2e/button.spec.ts`. The toggle implementation (spring return, three states, captions) is unchanged.
- **Task 2 (commit ff4b17a):** lamps and toggle moved to the Table G1 positions, `GEAR_BLOCK` exported from `plates.ts` and used by the shell for the heading and speed line baselines, the gear plate raised, `landing_gear` removed from `KNOWN_OPEN` (art-fit) and from `FOOTPRINT_KNOWN_OPEN` (layout test). New unit block "landing gear block order (G-2)".

## Deviations from Plan

1. **[Rule 1 - Gate could not pass as specified] Gear plate top 580 instead of 585, drawn under the PFD bezel (Task 2).** With the plate top at 585 the art-fit gate flagged the GEAR name (5.0 above the plate) and the unit footprint check flagged the lv.gear hit rectangle (top 581, 4 above). The lever must not move and its hit rectangle must not shrink, and the PFD bezel (region grown by 16) ends at 583, so a plain rectangle could not satisfy plate-over-bezel clearance and hold the lever. The plate now starts at 580 and the shell draws `strip-gear` before the display bezels so the bezel stays whole; only a 3 unit sliver of x 836 to 873 runs under the PFD bezel corner. The "no plate overlaps the bezel" unit case allows that one pair (strip-gear and pfd) and asserts the sliver is at most 4 units. Plate-over-plate and region checks are unchanged.
2. **[Rule 1 - Visual tuning] Toggle placed at global y 686 rather than 682.** The first screenshot showed the toggle captions crowded against the speed line; the toggle moved 4 units down (within tolerance 8 of the starting value). Reference row updated to 872, 686.
3. **[Rule 3 - Test row] `FOOTPRINT_KNOWN_OPEN` lost `landing_gear`** (the plan only names KNOWN_OPEN and TEXT_OVERLAP_KNOWN; no gear pair was in the text-overlap list after plan 16, so none needed removing).
