# Phase 01.1 Plan 14: Static levers and push buttons Summary

Every detent lever and push button now shows its state by position only: the state word under or beside the control is gone, lever legends no longer vanish near the handle, and tests/static-text.test.ts gates that lever and button text never changes with state.

## What was built

- **Task 1 (tracer, commit 03e4760):** `LeverBody` lost the state text and the variables that positioned it (compact flag, reach, stateY, hideDist). Legends are static: vertical skinned levers keep printing all legends to the right of the handle; the horizontal skinned slider (CIRCULATING AIR) prints both legends under the slot ends, below the handle's cross extent. Lever unit tests expect zero state texts and the e2e specs assert `data-state`. The static-text gate expands every lever of DA50RG at every detent (all 21 POWER steps included) and requires an identical sorted text list and at most 40 elements.
- **Task 2 (commit 180f847):** `RoundBody`, `LegacyBody` and `SpringBatBody` print no state text; `buttonTextLayout` returns label size, lines and baselines only (state size, baseline and width fields removed, along with the state-label helper). Pressed rings and cap shapes are unchanged. Button tests assert no state text, the clearance case checks the label only, and the gate checks every button in every state (both held sides of the spring toggle) plus the two spring-toggle captions. e2e button and inventory specs assert `data-state`.

## Deviations from Plan

None in behavior. Notes:

1. **[Test] Duplicate assertions dropped:** where an e2e state-text assertion sat directly under a `data-state` assertion for the same value, the state-text line was deleted instead of replaced. The GEAR initial-state case got a new `data-state` `up` assertion.
2. **[Cleanup] Lever font-size test:** the allowed-size list no longer needs the `compact ? 8 : 10` entry.

## Assumptions taken

- Legend row for the horizontal slider placed at `art.across + 8` (19 units for the env-slider), inside the 40-high footprint and the region; the unit test requires it below the 11-unit handle half-width.
