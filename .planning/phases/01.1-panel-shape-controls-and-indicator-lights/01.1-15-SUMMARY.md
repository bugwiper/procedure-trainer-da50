# Phase 01.1 Plan 15: Static knobs, no lamp readouts, built-panel text gate Summary

The last dynamic text on the panel is gone: the words under the gear and flap lamps and the stop word on every knob. A built-panel Playwright spec now keeps it that way.

## What was built

- **Task 1 (tracer, commit 5a30927):** `defineIndicators` takes the lamps only and returns `indicators`, `get` and `inRegion`. `IndicatorGroupSpec`, `groupsInRegion`, `gearReadout`, `flapReadout`, the group list and the `IndicatorReadout` component were deleted; `Panel` renders lamps only. `gearLamps`, `flapLamps`, lamp ids, positions, colours, captions and art are untouched. Unit cases for readouts, groups and readout clearance were deleted; a new assertion pins the set's keys to `get`, `inRegion`, `indicators`. The e2e indicator spec lost its readout and group cases; the lamp-lit assertions stay.
- **Task 2 (commit b0894e4):** `RotaryBody` no longer draws the state text (and the layout branch that only placed it). Name placard, scale marks at every stop, pointer, knurl and pressed ring stay; stops, angles, tap halves and drag logic are untouched. New unit cases: no state text at any stop, identical sorted text strings at every stop (the stop labels remain part of the printed scale), at most 40 elements, the pointer follows the drag angle and otherwise rests at the committed stop. The knob family joined `tests/static-text.test.ts`. `e2e/rotary.spec.ts` asserts `data-state` stop ids instead of the text marker.
- **Task 3 (commit 8c961ac):** `e2e/static-text.spec.ts` asserts zero `data-state-text` and `data-indicator-group` elements on the built panel, then reads all svg text strings, operates sw.light_landing (rocker), sw.alternator_1 (bat), the ENGINE softkey, one INSTRUMENT LIGHT step, GEAR down, FLAPS LDG and the de-ice guard lift (all through `data-hit` and `data-detent` targets, no test-only hook), and asserts the list is unchanged. The seven lamp captions are asserted present in the list.

## Deviations from Plan

1. **[Rule 1 - Bug in plan assumption] Glass text excluded from the text gate (Task 3).** Operating the ENGINE softkey switches the MFD between the MAP page and the ENGINE page, which changes the MFD's gauge texts (RPM, FUEL QTY RH, NORTH UP and so on). Comparing every svg text string therefore failed on first run. The spec now skips text inside the `pfd` and `mfd` regions unless it sits inside a control (the softkey keeps its own checked text). All placards, captions, scale marks and lamp captions on the rest of the panel are still compared. Glass content is instrument data, not a control label, so this does not weaken G-0.1.
2. **[Format] tests/indicators.test.ts:** Task 1 left a Prettier violation (found by `format:check` in Task 3); fixed in the Task 3 commit.
3. **[Test] Type-scale case:** `tests/rotary.test.ts` required at least three font-size declarations in Rotary.tsx; two (6 and 8) remain after the removal, so the bound became two.
