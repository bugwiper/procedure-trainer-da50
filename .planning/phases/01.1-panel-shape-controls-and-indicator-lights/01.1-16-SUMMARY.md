# Phase 01.1 Plan 16: Plates as data and the art-fit gate Summary

The visible plates of the panel are data now, a built-panel gate measures every region's art against its region and plate, and the owner's overflow reports for FADEC, the flap block and LEVEL are fixed, together with every other overflow outside the areas plans 17 to 22 rebuild.

## What was built

- **Task 1 (tracer, commit b47c925):** `plates.ts` holds `PLATES` ({id, x, y, w, h, rx, regions}); `PanelShell` draws every plate through one `Plate` component (`data-plate`, `data-plate-regions`); the `data-shell` group names are unchanged. `tests/layout.test.ts` gained a `plates` block. `e2e/art-fit.spec.ts` reads each region's art in svg units (hit rectangles, detent markers and the region frame excluded) and compares it with the region frame and the carrying plate (0.75 unit tolerance). Run against the old engine plate (top 485) the gate reports `engine_controls: text "FADEC" leaves plate engine (top by 8.0)`; with the plate at 474 it passes.
- **Task 2 (commit cd918e4):** the switch strip is three plates (`strip-switch-row`, `strip-gear`, `strip-flaps`) with seams at x 836 and x 1150, so LEVEL (centre 1099) and its caption lie fully on `strip-gear`. The flap region grew upward and its plate with it (G-4). A second gate case checks that the RUBIN mark lies on `strip-flaps` and every LEVEL element on `strip-gear`.
- **Task 3 (commit a4e80fd):** the light knobs, the switch row and the two under-panel regions grew upward; the text-overlap gate was added; `KNOWN_OPEN` holds only the six Table K1 regions.

## Deviations from Plan

1. **[Rule 1 - Table P2 adjusted] Flap plate top 608, not 612 (Task 2).** The "FLAPS" lever name sat 2 units above the flap region and 1 unit above a plate at 612, so the plate (612) could not hold the art. The region cannot grow without the MFD softkey region giving way; the softkey (a single 36 x 36 key at global y 571 to 607) leaves its region 4 units to spare, so the softkey region now ends at 608 and the flap region and plate start there. The lever name baseline moved to 6.5 in the region (`nameInset` for `flaps-block`). Lever and lamp positions are unchanged globally.
2. **[Rule 1 - Overflow outside the plan's list] Task 3 fixes.** The first red run also flagged: the INSTRUMENT and FLOOD captions (1.6 above the region), the ELECT. MASTER caption (1.5 above region and plate), the EMERGENCY GEAR EXTENSION name (4.0) and the ALTERNATE AIR name (1.0). Each was fixed by growing the region (and for the switch row also its plate) upward, per the plan's fix order. `nameInset` 6.5 for `pull-tab` (was 2) and `pull-boot` (was default 4) keeps the whole name inside the region.
3. **[Rule 3 - Test infrastructure] `ART_FIT_STRICT=1`.** Added to the spec so a later plan can see what its rebuilt region still has to fix without editing `KNOWN_OPEN`. Not in the plan; harmless when unset.
4. **[Rule 1 - Gate precision] The text-overlap gate compares the glyph band (middle 60 percent of the text box).** The full text box includes ascent and descent, so every multi-line placard (ESS BUS NOT FOR NORMAL OPERATION, EMERGENCY GEAR / EXTENSION, FUEL / TRANS, STALL / GEAR / TEST) overlapped itself on the first run. The band is about the cap height. The same spec also fails on stale `TEXT_OVERLAP_KNOWN` entries so the list cannot hide a regression.
