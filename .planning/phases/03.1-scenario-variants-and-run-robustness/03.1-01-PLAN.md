## Decisions (assumptions taken in planning; the owner may veto any of them)

- **V-01** A variant has `id`, `weight` (integer 1 to 100), `controls`, `parameters`, `applies` (ids of steps and forbidden items that apply in it) and `debrief` (own-wording cause line). A step or forbidden item named by no variant applies in all variants; one named by some applies only in those. No `quantities` (see the todo for ENG OIL TEMP).
- **V-02** `controls` are the faulted control state, like faulted parameters: in force from t 0 on Easy and Medium, set by the simulation at the onset on Realistic (new `onset.controls`, filled from the variant), so the Realistic start stays clean.
- **V-03** `resolveVariant(scenario, id, realistic)` returns a plain derived scenario (controls and parameters laid over, steps and forbidden items that do not apply removed, every node kept so branch paths and the printed outline stay those of the file). Sim, grade and lint then run on it unchanged. A scenario without variants resolves to itself.
- **V-04** A recording that names no variant (every hand-written golden) grades as the FIRST variant of the file. `alternator_dead` (today's behaviour) is declared first. `GradeResult.variant` exists only when the recording names one.
- **V-05** Drawn at run start on all three levels: a second seed (after the onset seed, only when the scenario has variants), `variantFromSeed` = first mulberry32 value times the weight total, cumulative. Recorded as `Recording.variant {id, seed}`. ALTN 1 FAIL weights: alternator_dead 40, breaker_popped 30, alternator_shorted 15, breaker_popped_dead 15.
- **V-06** A control change made by the simulation is a real log event: `store.inject` appends an event with `source: 'sim'`. It is never retractable, is not part of the Recording, is regenerated by every replay and arms no reaction.
- **V-07** Printed row 1 of ALTN 1 FAIL becomes the graded step `alt1_breaker_in` (critical, applies in `breaker_popped` only); its printed text is unchanged. In the other variants that row shows muted in the debrief. Doing the later steps in `breaker_popped` is ungraded, not harmful.
- **V-08** The debrief prints one line `Cause: <variant debrief>` after the level line, after the run only.
