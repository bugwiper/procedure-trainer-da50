## Decisions (assumptions taken in planning; the owner may veto any of them)
All numbers are instructor-review values or layout assumptions, none is an AFM figure. Owner answers of 2026-10-27 (todo `2026-10-23-realistic-level-visual-cues.md`) are built in: Ground Idle is plain idle (lever position p0), the fuel valve lift is not modelled, the red release lever is the window control.
- **P-01** The toe brakes are ONE control `lv.toe_brakes` (detent-lever, tapToggle, detents released and applied, ids with the existing `lv.` prefix because the label table accepts only the known prefixes), drawn as two pedals with a toe pad each under one footprint. A step reads one control (the predicate vocabulary is closed), and a latching brake suits touch (a finger cannot hold a pedal while the other hand works the panel). Two pedal controls would need an "all of" predicate in schema, lint and grading; the parking brake `lv.parking_brake` stays separate.
- **P-02** Pedals and plate sit at the floor of the pilot's footwell: region `pedals` x 300, y 1150, 360 x 110, plate `pedals-pad` x 280, y 1130, 400 x 150, centre of the control at global 480, 1205. Below the old transponder plate, so the transponder can move in task 2 without a clash.
- **P-03** Ground speed: hidden quantity `ground_speed_kt` (0 to 100, base 0), parameter `ground_roll` (0 or 1, normal 0). Only a scenario that sets it gets the model; every other run holds the speed it starts with, so the cruise scenarios and every recording stay bit for bit. On Realistic the parameter acts from the onset, so the speed holds for the first 2 to 6 s.
- **P-04** The roll scene follows the speed through a new cue `roll_speed` (0 to 60 kt, full rate from 60). The playback rate changes continuously (Animation.updatePlaybackRate) so the marks never jump; rate 0 is the stopped scene. Reduced motion keeps no animation as before.
- **P-05** The transponder moves beside the buttons: session plate x 1280, y 760, 480 x 520 (region 1300, 780, 440 x 480, buttons 370 wide), transponder plate x 1780, y 760, 360 x 240 (region 1800, 780, 320 x 200, keypad centre local 160, 100).
- **P-06** CHOOSE SITUATION pages: four rows per page, NEXT PAGE beside CLOSE LIST on the top row, drawn only when more than four situations exist, wraps to page 1. Needed because this phase adds six situations to a list built for four (the guard test U-08 would fail otherwise).
- **P-07** Emergency window: lever `lv.emerg_window` (detent-lever, tapToggle, detents closed and open) with the oval outline in the same skin, region `side_window` x 4, y 205, 64 x 265 on a plate `side-pane` (x 2, y 202, 70 x 270), far left of the instrument panel. Not in the windscreen strip: that region is art only and a control there would split it.
- **P-08** The tap-toggle rule of the registry widens to a set of skins (parking-flap, toe-brakes, window-release), both or neither, as before.
