## Data tables

Table D1, rewrite rules (apply by meaning, line by line; find the lines with a case-insensitive search for the old format word):

| Old content | New content |
|-------------|-------------|
| the scenario format word in any statement about scenario files, packs, the schema or the authoring guide | TOON (files `scenarios/<pack>/<name>.toon`, manifest `scenarios/<pack>/pack.toon`) |
| the old parser package row, its version and its position API | `@toon-format/toon` 4.4.0, pinned exactly (Working Draft spec, 11 releases in 11 months); `decode` in strict mode throws ToonDecodeError with a 1-based line; schema errors get line and column from the project's own path-to-line index (`src/scenario/toon-index.ts`) |
| JSON-Schema editor autocomplete through a language-server header | no editor schema support for TOON; the authoring feedback is `npm run validate` (file:line:col) and the Vitest check that validates every shipped file; `z.toJSONSchema` stays an optional documentation artifact for the Phase 4 authoring guide |
| the old `import.meta.glob` pattern for scenario files | manifests `/scenarios/*/pack.toon` eager, scenario files `/scenarios/*/*.toon` lazy with query `?raw`, grouped into one chunk per pack (Vite 8 `build.rolldownOptions.output.codeSplitting`) |
| "do not use" rows about other parsers of the old format, boolean coercion of `no`/`off`, build-time plugins for the old format | TOON pitfalls instead: exact pin and a conformance test before any upgrade, strict decoding (array counts `[N]` must match), quote numeric-looking strings (`issue: "018"`), comments only as full lines starting with `#`, no tabular rows or root arrays, never auto-format scenario files with the library encoder (it drops comments); no build-time scenario plugin (runtime parse keeps line-numbered errors and the later encrypted-pack path) |
| probe or rationale sentences that cite the old parser | restate the claim for TOON or delete the sentence when it has no TOON equivalent |
| PROJECT.md "Content format" constraint and "Active" item | TOON scenario files with schema validation and line-numbered errors, manually extensible |
