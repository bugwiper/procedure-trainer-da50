## Phase goal

Users can start one real emergency (Oil Temp High, CAS message ENG OIL TEMP), run the procedure by operating the panel, finish with "Procedure complete" and receive an objective PASS/FAIL debrief (ROADMAP phase 2).

<objective>
Wire the pilot's path end to end on the built panel: NEW SITUATION in the co-pilot legroom loads the blueprint scenario through the pack seam, the panel takes the scenario's initial state, the user operates THROTTLE and COWL FLAP, presses "Procedure complete" in the footer and reads a PASS or FAIL debrief. Then pin the session contract with unit tests.

Purpose: SES-01 (new situation, random), SES-03 (silent exam ended by Procedure complete), SES-04 (PASS/FAIL and per-step verdicts), SCN-05 and D-13 (graded from the resulting state of the recorded log); D-14 (non-modal app, session area in the co-pilot legroom), D-15 (footer button), D-16, D-18, U-02, U-10.
Output: the session state machine, the session buttons and area frame, the action press class, the footer button, the debrief, an e2e spec, the session unit tests.
</objective>

Table N1, session (src/ui/session.ts, `createSession(deps)`; deps = `{ bridge, packs: { provider, policy }, env, rng, onRunStart }`; no DOM access, so it is unit tested in node):

| Member | Contract |
|--------|----------|
| screen | read-only signal `'free' \| 'running' \| 'debrief'` (plan 11 adds `briefing`, plan 12 `choosing`) |
| scenario, result | the scenario of the current or last run and its GradeResult (null until graded; cleared at the next start) |
| busy | true while a pack loads; presses on the area are ignored meanwhile |
| loadFailure | the failed OpenResult or null (plan 12 renders it) |
| clock | the VirtualClock of the current run or null |
| newSituation() | only in `free` and not busy: the scenario entries of every pack the policy allows, in manifest order, one picked by `pickRandom(entries, rng)`, opened with openScenario and started; a failure sets loadFailure and stays in `free` |
| start (internal) | bridge.reset(initial.controls, initial.quantities), a new VirtualClock, bridge.setTimeSource(clock.now), onRunStart() (App: zoomOut to the full panel), screen `running` |
| complete() | only in `running`: Recording = `{ scenarioId, completedAt: clock.now(), events: store.events() mapped to t, id, value }`, result = grade(scenario, env, recording), clock paused, time source cleared, screen `debrief` |
| closeDebrief() | `debrief` to `free`; the control state and the quantities stay as the run left them (U-10) |
| pickRandom(items, rng) | item at `min(n - 1, floor(rng() * n))`; throws RangeError for an empty list |
