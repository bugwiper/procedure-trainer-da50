## Data tables

Table L1, validation rules (lint returns issues with a path; checkScenario locates them; L1 to L3 exist since plan 01):

| Rule | Issue when |
|------|-----------|
| L1 | an initial.controls key is not a registry control, or its value is not a legal state of it |
| L2 | an initial.quantities key is not a quantity, or its value lies outside min..max |
| L3 | a predicate (done, trigger, when) names an unknown control, an illegal state, a travel check on a control that is not a detent lever, an unknown quantity or an unknown band of that quantity |
| L4 | two of the group, step and forbidden ids of one scenario are equal |
| L5 | a graded step's done already holds in the initial state (the do-nothing replay would credit it, RESEARCH Pitfall 7) |
| L6 | a watched forbidden trigger already holds in the initial state |
| L7 | a path through the procedure has more than 3 branch levels (decision branches and standalone branches both count; UI-SPEC outline cap) |
| L8 | a branch decided during the run (decided_at run) contains a group, directly or below (format 1 grades no steps that depend on the run) |
| L9 (validateAll) | a manifest is missing or invalid; a manifest entry names a file that does not exist; a scenario file of the folder is not listed; a scenario id differs from its entry id; an entry title differs from the scenario title; entry ids repeat |

Table V1, validate command:

| Item | Contract |
|------|----------|
| `checkScenario(text, env)` (src/scenario/lint.ts) | parseScenario, then lintScenario, every issue located with `locate(indexToon(text), path)`; returns `{ ok: true, scenario }` or `{ ok: false, issues }`, each issue with path, message, line and col; openScenario uses it |
| ScenarioIssue | line and col become required fields |
| `validateAll(packs, env = DA50RG_ENV)` (src/scenario/validate-all.ts) | input: `{ dir, id, manifestText, files: { name, text }[] }[]` with dir the repo-relative pack folder; output: `{ file, line, col, message }[]` sorted by file, then line, then column |
| `formatIssue(issue)` | `<file>:<line>:<col>: <message>` |
| scripts/validate-scenarios.mjs | argument: the root folder (default `scenarios`); one pack per subfolder; Vite `createServer({ server: { middlewareMode: true, ws: false }, appType: 'custom', logLevel: 'error', optimizeDeps: { noDiscovery: true } })`, `ssrLoadModule('/src/scenario/validate-all.ts')`, close the server in `finally`; prints every issue, then `<n> scenario files checked, <m> problems`; exit code 1 when m > 0 (RESEARCH Pattern 6: Node type stripping cannot import the extensionless modules) |
| package.json | script `validate` = `node scripts/validate-scenarios.mjs`; `format` and `format:check` also cover `scripts` |
