## Data tables

Table N2, session additions (src/ui/session.ts):

| Member | Contract |
|--------|----------|
| screen | gains `choosing` (the area shows the list; not a modal) |
| choices | the entries `{ pack, scenario, title }` of every allowed pack in manifest order, filled by openChooser |
| openChooser() | free only: list packs through the provider and the policy; no entries opens the empty message; else screen choosing |
| closeChooser() | choosing to free |
| chooseScenario(ref) | choosing only: load and open the briefing of that entry (same path as newSituation after the pick) |
| confirm | null or the pending action (`new`, `choose`) asked for during a run |
| request while running | newSituation and openChooser in `running` set confirm instead of acting |
| keepGoing() | clears confirm; the run continues unchanged |
| leaveRun() | ends the run without grading: bridge.reset with no baseline and the idle quantities, clock dropped, time source cleared, screen free, then the pending action runs |
| loadFailure, retryLoad(), dismissFailure() | the failed request is kept; retryLoad repeats it (random pick again, or the same chosen entry); dismissFailure returns to free |
| empty, dismissEmpty() | true when a listing found no allowed scenario |
| busyKey | the session-hit id of the button that started the current load; null otherwise |

Table K3, Confirm modals (src/ui/screens/Confirm.tsx on the modal shell; UI-SPEC Copywriting Contract):

| Kind | Content | Escape |
|------|---------|--------|
| leave | heading "Leave this run?", body "The current run ends without a result.", Keep going (primary, focused), Leave run (outline: transparent, 1 px `#ff5a50` border, `#ff5a50` text) | Keep going |
| error | role alertdialog, heading "This situation could not be loaded." in `#ff5a50`, body "Check your connection, then try again.", Try again (primary), Back to panel (secondary) | Back to panel |
| empty | heading "No situations available", body "Reload the page. If this stays, the scenario files are missing from this build.", Back to panel (primary) | Back to panel |

Table A2, the choose view (Table A1 of plan 04, Table SB of plan 06 and the UI-SPEC): CLOSE LIST at local (20, 20, 780 x 80); rows at y 110, 200, 290, 380 (x 20, w 780, h 80) with the manifest title as label (size 14, weight 700); aria-labels "Close list" and "Open briefing: {title}"; the main view adds CHOOSE SITUATION at (20, 160, 780 x 120) with aria-label "Choose situation"; the rows and CLOSE LIST ignore activations for 400 ms after the view appears (the shell's `isShielded`); during a load the busy button keeps its pressed rim and every other press on the area is ignored.
