## Phase goal

Users can start one real emergency (Oil Temp High, CAS message ENG OIL TEMP), run the procedure by operating the panel, finish with "Procedure complete" and receive an objective PASS/FAIL debrief (ROADMAP phase 2). The scenario controls live in the co-pilot legroom (D-14 amended) and must stay usable at every zoom level.

<objective>
Make the session area as safe to use as every other panel region: the Full panel button avoids it, its buttons reach 44 px when zoomed, double taps on its buttons never zoom, and layout gates pin its plate, its region and the empty pilot legroom.

Purpose: D-14 (session controls in the co-pilot legroom; pilot legroom reserved), UI-SPEC "Session Control Area" (tap-size budget, gesture contract), U-05, U-07, U-13.
Output: session footprints in the corner chooser, layout and zoom unit gates, an e2e spec over the area, an updated shared zoom helper.
</objective>
