## Phase goal

Users can start one real emergency (Oil Temp High, CAS message ENG OIL TEMP), run the procedure by operating the panel, finish with "Procedure complete" and receive an objective PASS/FAIL debrief (ROADMAP phase 2). Success criterion 2: the panel opens in the scenario's initial state with "OIL TEMP HIGH" (the real CAS text ENG OIL TEMP, D-06a) showing in the alert area.

<objective>
Show the annunciation where the pilot expects it: a rule of the aircraft CAS table turns the scenario's oil temperature into the red ENG OIL TEMP chip on the PFD, and the MFD oil gauges show the scenario values. Then bind the MFD bands to the quantity data and make validation compare the scenario's annunciations with the rules.

Purpose: PNL-03 and SCN-03 (annunciations), D-06, D-06a, D-07, D-07a, D-08 (quantities drive instruments and annunciations; the seam for Phase 3 live values), U-09 (chip geometry from the frame constants, rechecked against the owner's reference image when it arrives), U-10.
Output: the CAS rule table and engine, the chip group on the PFD, the bound MFD gauges, lint rule L10.
</objective>

## Data tables

Table K1, CAS rules (src/aircraft/da50rg/cas.ts; AFM 03-08, the trigger fact recorded in the private afm-notes):

| id | text | level | when |
|----|------|-------|------|
| eng_oil_temp | ENG OIL TEMP | warning | quantity oil_temp_c gt 125 |

Engine contract (src/engine/cas.ts): CasRuleSpec `{ id, text, level: 'warning' | 'caution', when: Predicate }`; `defineCasRules(specs, env)` throws a CasError naming the rule for a duplicate or malformed id (`^[a-z][a-z0-9_]*$`), a text outside 1 to 12 characters or not upper case (letters, digits, space, slash), an unknown level, or a predicate whose references do not resolve; it returns a frozen CasRuleSet `{ rules, get(id), active(ctx, env) }` where `active` returns `{ id, text, level }[]` with warnings first, then cautions, each in table order. AircraftEnv gains `cas: CasRuleSet`; DA50RG_ENV gains DA50RG_CAS.

Table K2, the chip (UI-SPEC "CAS Chip on the PFD"; PFD region-local units, region 495 x 367):

| Item | Value |
|------|-------|
| block | rect w 100, h 20, rx 2, fill `#000000`, no stroke |
| text | font-size 10, weight 700, text-anchor middle at block centre, baseline block top + 14, all caps |
| colours | warning text `#f0443c`, caution text `#f2c230` |
| slots | row 0 at y 236; right slot x 294, left slot x 190; row n at y = 236 - 24 n; order: row 0 right, row 0 left, row 1 right, ...; at most 3 rows (6 chips), further chips are not drawn |
| DOM | `<g data-testid="cas-chips">`; per chip `<g data-testid="cas-chip" data-cas-id data-level role="img" aria-label="Warning: ENG OIL TEMP">` (Caution for a caution); pointer-events none; no aria-live |
