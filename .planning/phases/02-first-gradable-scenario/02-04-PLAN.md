## Data tables

Table B1, store and bridge (RESEARCH Pattern 4; WR-07 folded):

| Member | Contract |
|--------|----------|
| deriveState(registry, events, baseline = {}) | registry defaults, then the baseline, then the events in order |
| PanelStore.reset(baseline = {}) | every entry must name a registry control and one of its legal states, else RangeError naming the id; sets the baseline, empties the log, sets the consumed watermark to -1, rebuilds the state, calls the onReset listeners; creates no event and calls no dispatch listener |
| PanelStore.onReset(listener) | returns the unsubscribe function (same pattern as onRetract) |
| PanelStore.baseline() | frozen copy of the current baseline |
| PanelStore.retract | rebuilds from the baseline (a double tap never snaps POWER from p75 to the registry p70) |
| events | each event object is frozen when created; `events()` returns a new array of the frozen objects |
| createPanelBridge(registry, indicators?, aircraft?) | `aircraft` is `{ quantities: QuantitySet }` (DA50RG_ENV satisfies it; plan 06 passes it from App) |
| bridge.quantities | read-only signal of the quantity values; starts at the idle values (empty without aircraft) |
| bridge.reset(controls, quantities?) | store.reset(controls); every control signal refreshed by onReset (lamps follow); quantities = idle values overlaid with the given ones (D-08 seam) |
| bridge.setTimeSource(now or null) | actuate stamps events with now(); null restores performance.now |

| region `scenario_area` | name `SESSION`, bounds x 1300, y 780, w 820, h 480, no registry controls |

| label rule | label size 14, weight 700, text-anchor middle at local x 410, baseline top + h / 2 + 5 (data only here; plan 06 draws the buttons) |
