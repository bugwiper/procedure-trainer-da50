## Data tables

Table T1, debrief copy rules (src/ui/debrief-text.ts; UI-SPEC "Debrief" and Copywriting Contract):

| Function | Rule |
|----------|------|
| reasonLines(result) | pass: "All critical steps done."; fail: one line per cause in reason order, each cause once: critical_missed count 1 "1 critical step was missed.", count n "{n} critical steps were missed."; order "Steps were done in the wrong order."; forbidden "A harmful action counts as a fail in this scenario." |
| formatClock(ms) | whole seconds rounded down, shown as m:ss (0 gives 0:00, 65999 gives 1:05) |
| orderLine(group, result, scenario) | unordered group: none; ordered group without violation: "Order kept"; else one line per violation "Order wrong: {text of expected} was expected before {text of before}" |
| harmful section | heading "Harmful actions ({n})"; one row "{text} at {formatClock(t)}" per entry in log order; "None." when empty |

Table E4, e2e additions:

| Spec, case | Expectation |
|------------|-------------|
| scenario.spec, harmful action reported | start, tap the POWER marker p100, wait at least 1.5 s, tap p50 and COWL FLAP open, Procedure complete: PASS, "All critical steps done.", "Harmful actions (1)", a row matching "Increase power at 0:0" followed by a digit |
| replay.spec, `@hooks` UI verdicts equal a replay | after a golden run that also double-taps a latching control once (zoom and retract, D-13), the spec builds the Recording from `__panel.events()` and the session's completion time, parses the blueprint from scenarios/engine with checkScenario, grades it with DA50RG_ENV and deep-equals `__panelSession.result()` |
| replay.spec, `@hooks` the exam stays silent | during a run with three actuations: no element with aria-live, role alert or role status (the rotate hint excepted), no open dialog, `__panelSession.result()` null, the footer text unchanged apart from the run button |
