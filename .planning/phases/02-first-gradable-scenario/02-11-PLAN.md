## Data tables

Table O1, outline view model (src/ui/outline.ts; `buildOutline(scenario, branches, mode, result?)`; the paths are those of branchStatuses):

| Node | Briefing form | Debrief form |
|------|---------------|--------------|
| line | text | text with the note "Not graded"; muted when an enclosing branch does not apply (then no note) |
| decision | text, its branches nested one level in | text with "Not graded", its branches nested |
| branch, status applies | label, children (without steps) | label, children with verdicts |
| branch, status not_applicable | label and the word "Not applicable", no children | label and "Not applicable", children muted without tag or verdict |
| branch, status open | label, children | label, children as non-graded lines |
| group | omitted with all its steps | its steps at the group's level (plan 13 adds the order line under an ordered group) |
| step | omitted | severity tag, text, verdict: Done when credited; Missed (critical or standard) or Not done (optional) when not; muted without tag or verdict under a not-applicable branch |

ChecklistOutline (hook-free, so tests/vnode-walk.ts can expand it): nested `ul` and `li`; each level `padding-left: 16px` with a 2 px left rule `#3a424b`; branch labels in Label style; "Not applicable" and "Not graded" in Meta style; muted text `#aab3bd`; tag CRITICAL, STANDARD or OPTIONAL in Label caps `#aab3bd`; verdict words Done `#2fd36f`, Missed `#ff5a50` (critical) or `#f2c230` (standard), Not done `#aab3bd`; on narrow screens a step row wraps with tag and verdict on the first line.

Table B2, briefing (UI-SPEC "Briefing", Copywriting Contract), on the modal shell with id `briefing`, Escape = Back to panel:

| Order | Content |
|-------|---------|
| 1 | Heading: scenario title (labels the dialog) |
| 2 | Situation (Body) |
| 3 | Meta: `Source: {source.section}, issue {source.issue}`, then `{source.document}, checked {source.verified}` |
| 4 | Meta: the short text of DISCLAIMERS[scenario.disclaimer] ("Training aid only. Not a replacement for the AFM or for instruction.") |
| 5 | Label "Steps outside the panel (not graded in this version)" and the briefing outline; omitted when the outline is empty |
| 6 | Meta: "Exam mode: no hints. When you are done, press Procedure complete." |
| 7 | Action row: Start run (primary), Back to panel (secondary) |

Table E2, e2e/scenario.spec.ts after this plan (every earlier case now starts through NEW SITUATION and Start run with one shared helper in the spec):

| Case | Expectation |

| Start run starts in the initial state | screen running, lv.power p75, view at the full panel |
