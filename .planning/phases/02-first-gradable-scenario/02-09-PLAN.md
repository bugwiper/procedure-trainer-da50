## Data tables

Table M1, the modal shell (src/ui/screens/Modal.tsx; UI-SPEC "Overlay mechanics", Spacing, Color):

| Item | Contract |
|------|----------|
| props | `id` (modal id), `labelledBy`, `role` (`dialog` default or `alertdialog`), `layer` (`modal` z-index 50 or `ack` z-index 60), `onEscape` (function or null), `actions` (the sticky action row), children |
| container | position fixed, inset 0, the scrim `rgba(11, 13, 16, 0.88)`, covers the panel's hit area so no pointer reaches the SVG; a backdrop tap does nothing |
| card | `#1b1f25`, 1 px `#3a424b`, max-width 560 px (narrow: 100 % minus 32 px), padding 16 px when the viewport is at most 500 px high, else 24 px, max-height `calc(100dvh - 32px)`, overflow auto, `touch-action: pan-y` |
| action row | sticky at the card bottom on the card background, buttons 16 px apart, every button at least 44 px high and 120 px wide; primary: fill `#8fb8e6`, text `#0b0d10` 14 px 700, radius 8; secondary: transparent, 1 px `#3a424b`, text `#e6e9ed` |
| focus | the first action (the primary) gets focus on mount; Tab and Shift+Tab cycle inside the card; on unmount focus returns to the element that had it at mount |
| keys | Escape calls onEscape; null does nothing |
| input shield | for `INPUT_SHIELD_MS` = 400 after mount every pointerdown, pointerup and click inside the container is stopped in the capture phase (pure helper `isShielded(openedAt, at)`) |
| clock | the shell calls holdModal(id) on mount and releaseModal(id) on unmount (src/ui/modals.ts: a signal holding the set of open modal ids, holdModal, releaseModal and a computed anyModalOpen) |

Table M2, acknowledgment (UI-SPEC "First-Run Acknowledgment", Copywriting Contract):

| Item | Value |
|------|-------|
| storage key | `da50.ack` (ACK_STORAGE_KEY), value the accepted version as a decimal string |
| version | ACK_VERSION = the version of DISCLAIMERS `training-aid` |
| required() | true unless storage holds exactly the current version or this session already accepted; a throwing or missing storage counts as not accepted |
| accept() | sets the in-memory acceptance first, then tries to write; a write error is swallowed |
| modal | layer `ack`, onEscape null, heading "Training aid only", the two body paragraphs, one primary button "I understand" |

Table CD, the clock driver (src/ui/clock-driver.ts; RESEARCH Pattern 5, UI-SPEC Clock row):

| Item | Contract |
|------|----------|
| attachClockDriver | `({ session, raf, cancelRaf, now, hidden, blocked })` returns a detach function; `session` is read through its `screen` and `clock` signals; `hidden()` and `blocked()` are predicates |
| frame | the elapsed time since the last frame is added to the session clock only while the screen is running, `hidden()` is false and `blocked()` is false; the step is clamped to MAX_FRAME_STEP_MS = 1000; the last frame time is updated on every frame, so a pause never accumulates time |
| App wiring | attached once with `requestAnimationFrame`, `cancelAnimationFrame`, `performance.now`, `document.hidden` and `anyModalOpen`; About holds the modal id `about` while open; overlays on the shell hold their own id |

|----------|-------------|
