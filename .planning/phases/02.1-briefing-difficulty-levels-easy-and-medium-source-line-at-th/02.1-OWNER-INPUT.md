## Grading semantics (UAT test 3, instructor answers)

- Times: no timing pressure in this scenario. Debrief must not show "at m:ss" for harmful actions here. Optional time limits per step ("reduce power within 20 s") stay possible for time-critical scenarios. Not used in the blueprint. The limit and its reference point (run start or onset) belong with Phase 3.
- Q1 end state vs action done: depends on the scenario. Intended final state means the step fails if the state is not held. Actions that helped but leave a different end state can be acceptable. To be designed in Phase 4 with the physics (for example temperatures back in green, pilot closes the cowl flap again to watch). Keep the current end-state rule for now.
- Q2 harmful actions: defined individually per scenario. In ENG OIL TEMP, increasing power must fail the run (`fails_run: true` on `power_increased`; golden recording "forbidden" turns FAIL; update GRADING.md and tests).
- Q3 order: default stays "order does not matter"; scenarios can mark a group as strictly ordered (`order_critical`). Example for later: emergency gear extension, pull the handle THEN gear lever down. Already supported; no change.
- Q4 branches decided during the run: later phase, as planned.
- New verdict "pass with recommendation": PASS when all critical steps and fail-run items are fine but something was not perfect (a missed standard or optional step, a harmful action that does not fail the run, an order violation in a group that is not order-critical). Derivable from the existing result lists. Name and wording to decide (owner said it may come later).
